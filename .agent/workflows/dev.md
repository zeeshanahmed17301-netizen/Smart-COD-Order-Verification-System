# Start Dev Server

// turbo-all

1. Install dependencies if `node_modules` is missing:
```bash
cd d:\COMSATS\FYP - Hamza\Code\frontend && npm install
```

2. Start the Vite development server:
```bash
cd d:\COMSATS\FYP - Hamza\Code\frontend && npm run dev
```

3. The server will be available at `http://localhost:5173` (default Vite port).
